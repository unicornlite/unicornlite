# Repository Guidelines

This is a static GitHub Profile README repository (`unicornlite`). There is no application code, no local build process, and no test suite.

- **Design Constraints (Crucial):** All edits to `README.md` MUST strictly follow the aesthetic defined in `PRD.md`. It relies on a monochrome/8-bit aesthetic (Black `#000000`, White `#FFFFFF`, and Grey `#888888`), with an allowed red accent (`#ff0000`) for specific creepy highlights (like the GitHub snake). Do not use colorful standard badges.
- **Auto-generated Assets:** The files inside `profile-3d-contrib/` and the SVGs generated for the snake animation are built automatically via GitHub Actions (see `.github/workflows/`).
- **Workflow:** Edit `README.md` directly. No local dev server or task runners are needed.
